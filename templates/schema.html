Doing the same thing from the command line

Everything above is also available in the sqlite3 shell, which is how we checked queries while building the app: 

$ sqlite3 database/farmfix.db
sqlite> .tables                        -- list tables
sqlite> .schema repairs                -- show one table's DDL
sqlite> PRAGMA table_info(repairs);    -- columns, types, PK flags
sqlite> PRAGMA foreign_key_list(repairs);
sqlite> PRAGMA foreign_keys = ON;      -- must be set per connection
sqlite> PRAGMA foreign_key_check;      -- should return nothing
sqlite> .headers on
sqlite> .mode column
sqlite> SELECT e.name, COUNT(*) AS jobs, SUM(r.cost) AS spent
   ...> FROM equipment e JOIN repairs r ON e.equipment_id = r.equipment_id
   ...> GROUP BY e.equipment_id ORDER BY spent DESC;
sqlite> .quit
